Term-in-Context Review Quest

Build Quiz Readiness

This review game helps you practice matching R course terms to realistic situations. Read the scenario first, then choose the term that best fits the situation.

The Quiz Readiness bar is not a grade. It is a practice signal. It starts at 0 and fills by 1 point each time you answer a question correctly. The goal is to notice what you know now and what you need to review before the Review Quiz.

Recommended first pass

Answer the questions in order without using the Back button, even if you miss one. That first pass gives you the clearest picture of where you currently stand.

After that, start the activity over or move forward and backward to learn the correct answers. You control how you use this guided review activity. It is a tool for learning and review, not a graded assessment.

1. Answer

Choose the best term for each scenario.

2. Read feedback

Use the feedback to see why the answer is right or why a distractor is close but wrong.

3. Review

Use the end screen to decide which topics need more study before the Review Quiz.
